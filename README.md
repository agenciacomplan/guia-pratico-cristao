# Guia Prático Cristão

Landing page estática de Ana Paula Benjamin.

## Publicação na Vercel

Importe este repositório na equipe Complan. Framework: Other. Diretório de saída: `dist`. Nenhum comando de build ou instalação é necessário. Adicione o domínio `www.guiapraticocristao.com.br` e use o registro DNS indicado pela Vercel para este projeto.

Os dois botões de compra apontam para o checkout Hotmart autorizado. Imagens WebP responsivas, carregamento tardio abaixo da primeira dobra e fontes locais.

A nota GTmetrix e o tempo de carregamento devem ser medidos após a publicação.
